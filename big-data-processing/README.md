# Технології обробки великих даних

- Інструменти: Python 3, pandas, numpy, matplotlib, Jupyter Notebook.
- Середовище: `.venv` у цій папці (спільне для всіх лаб предмету).
- Формат здачі: ноутбук `lab*.ipynb` з виконаними комірками + згенеровані файли (CSV, графіки) — усе в `lab-NN/submission/`. Ліміт кількості файлів: lab-01 — максимум 4 (графіки вбудовані в ноутбук, окремо не здаються).
- Вимоги до оформлення викладача: ще невідомі — уточнити.

## Дані (`data/`, формат Weka ARFF)

| Файл | Рядків | Задача | Примітки |
|------|--------|--------|----------|
| `houses.arff` | 7 | регресія: `sellingPrice` від площі, ділянки, спалень, граніту, ванної | дуже малий, навчальний |
| `bmw-training.arff` / `bmw-test.arff` | 3000 / 1500 | класифікація: чи відгукнувся клієнт (`responded`) | дати у форматі `YYYYMM`; у test є аномалія `FirstPurchase=8101` |
| `autoMpg.arff` | 398 | регресія: витрата пального (`class` = mpg) | 6 пропусків `?` у `horsepower` |

Класичні набори з туторіалів Weka. Імовірно, знадобляться в наступних лабах (регресія, класифікація, кластеризація). Читати в pandas через `scipy.io.arff` або пропустивши заголовок `@data`.
