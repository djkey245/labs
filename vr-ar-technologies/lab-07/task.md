# ЛР7 — Розпізнавання обличчя та фільтри для обличчя

Moodle: https://edu.regi.rovno.ua/mod/assign/view.php?id=323818
Методичка (PDF, скачана): `src/methodology.pdf`. Пакет: `src/BasicFaceFilterAssets.unitypackage` (Drive).

**Тема:** Вступ у Unity Engine. Доповнена реальність. Використання шаблону AR Mobile Template. Розпізнавання обличчя та фільтри для обличчя.

**Завдання 1.** Застосунок на AR Mobile Template + `BasicFaceFilterAssets.unitypackage` (за методичкою): сцена `Basic_Face_Filter`, префаб AR Default Face з матеріалом Face Debug MAT, AR Face Manager на XR Origin (Face Prefab), AR Camera Manager → Facing Direction = User, збірка APK. Результат: зелений фільтр на обличчі.

**Завдання 2.** За путівником Unity Learn «Створення інтерактивного фільтру для обличчя» (https://learn.unity.com/pathway/mobile-ar-development/unit/interactive-face-filter): сцена `InteractiveFilter`, пакет `Interactive_Face_Filter_Assets.zip` (InteractiveFaceFilter.unitypackage), три пари окулярів у префабі `GlassesGroup` (AR Face), `AR_Canvas` з кнопками окулярів і кольорів, вмикання/вимикання окулярів кнопками, зміна кольору матеріалом, збереження вибору (Visual Scripting у путівнику), опційно ocean-themed фільтр.

Примітка: Unity 2022.3 LTS або Unity 6000.0+. Звіт: назва/мета, висновки (особливості AR-застосунків, ігрові середовища, фізика в Unity), лінк на репозиторій, APK, скріни/відео.
